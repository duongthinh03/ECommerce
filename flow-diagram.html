3 Máy trạng thái — Đơn hàng & Thanh toán

2 trục độc lập: Order.Status (giao hàng) vs Payment.Status (tiền). Vd COD: Confirmed nhưng Unpaid tới khi giao.

stateDiagram-v2
    direction LR
    state "ĐƠN HÀNG" as O {
        [*] --> Pending
        Pending --> Confirmed
        Confirmed --> Packing
        Packing --> Shipping
        Shipping --> Delivered
        Delivered --> Completed
        Confirmed --> Cancelled
        Delivered --> Refunded
    }
    state "THANH TOÁN" as P {
        [*] --> Unpaid
        Unpaid --> PendingPay
        PendingPay --> Paid
        PendingPay --> Failed
        Paid --> RefundedPay
    }
